# text-adventure-python
## not finished!
There is improvement to be made. Also there was supposed to be doors...
I may or may not keep working on this project.
The existing scenes are placeholders created with chatgpt.

This is a simple Python-based text adventure. You can move between scenes, examine objects, and find items to use.

## Requirements
- Python 3.0 or higher
- folder structure is mandatory

## How to Play
Combine action keywords ('examine', 'move to', 'use') with objects, items, or scenes.

Examples:
- 'move to hallway'
- 'examine rug'
- 'use key cabinet'
