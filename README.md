## What it is
This is a simple Python-based text adventure, using the JSON library. You can move between scenes, examine objects, and find items to use.
It uses JSON files to store and retrieve game information. It was created as a learning exercise while following turorials (and got out of hand, oof!).


## Requirements
- Python 3.0 or higher
- folder structure is mandatory

## How to Play
Combine action keywords ('examine', 'move to', 'use') with objects, items, or scenes.

Examples:
- 'move to hallway'
- 'examine rug'
- 'use key cabinet'
